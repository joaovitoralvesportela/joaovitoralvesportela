## 🚀 Sobre mim

Sou estudante de desenvolvimento de sistemas e apaixonado por tecnologia. Gosto de transformar problemas em soluções por meio de software, explorando desde interfaces desktop e web até sistemas embarcados e algoritmos.

Atualmente, estudo e pratico desenvolvimento com **Java, Python, JavaScript, Rust e HTML/CSS**, além de bancos de dados como **MySQL e PostgreSQL**.

- 🎓 Técnico em Desenvolvimento de Sistemas pelo Senac
- 🧩 Interesse em desenvolvimento de software, interfaces e programação orientada a objetos
- 💻 Sempre criando projetos para estudar novas tecnologias e fortalecer meus conhecimentos
- 🎯 Buscando evoluir como desenvolvedor e construir uma base sólida em engenharia de software
